# ☕ Aroma Beans Consultant

AI-консультант интернет-магазина кофе: подбирает кофе под вкус и способ
заваривания, объясняет помол, хранение, доставку и подписку, рекомендует
товар из каталога.

Демонстрационный проект. Каталог и база знаний по умолчанию — встроенные
демо-данные; реальный магазин, оплата и доставка не подключены.

## Возможности

- диалог с Gemini на стороне сервера;
- системный промпт с ролью и границами: без медицинских советов и тем вне кофе;
- каталог товаров и база знаний из Google Sheets или встроенного демо-набора;
- карточка рекомендованного товара рядом с чатом;
- быстрые категории: вкус, помол, подписка, хранение, доставка, оборудование;
- адаптивный интерфейс React.

## Стек

React 19, TypeScript, Vite, Tailwind CSS 4, Express, `@google/genai`,
Google Sheets API, `dotenv`.

## Как это работает

```
React (src/App.tsx)
      │  POST /api/chat
      ▼
Express (server.ts)
      ├── Google Sheets → товары и база знаний (при наличии ключей)
      ├── системный промпт + каталог
      └── Gemini API → ответ и рекомендованный товар
```

- Данные из Google Sheets читаются при старте. Без ключей используется
  встроенный демо-каталог.
- Провайдер модели — Gemini; ключ остаётся на сервере и не попадает в
  клиентский бандл.

## Запуск

```bash
npm install
cp .env.example .env.local
# вписать GEMINI_API_KEY
npm run dev
```

Приложение — <http://localhost:3000>.

### Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `GEMINI_API_KEY` | да | ключ Google AI Studio / Gemini API |
| `GOOGLE_SHEETS_ID` | нет | ID таблицы с товарами и базой знаний |
| `GOOGLE_APPLICATION_CREDENTIALS_JSON` | нет | JSON сервисного аккаунта одной строкой, доступ только на чтение |
| `APP_URL` | нет | адрес размещения приложения |

### Google Sheets

Если заданы `GOOGLE_SHEETS_ID` и ключ сервисного аккаунта:

- лист с названием, содержащим `product`, читается из `A2:G100`:
  `id, название, категория, описание, цена, картинка, ссылка`;
- лист с названием, содержащим `know`, читается из `A2:B100`:
  `тема, содержание`;
- если листов с такими названиями нет, берутся первый и второй листы.

Без этих переменных приложение работает на демо-данных.

## Сборка

```bash
npm run build
NODE_ENV=production npm start
```

## Ограничения

- Нет авторизации и серверной истории: история диалога живёт в состоянии
  страницы и пропадает после перезагрузки.
- Нет оформления заказа, оплаты и проверки наличия.
- Ответы Gemini не являются медицинской рекомендацией.
- Проект собран в Google AI Studio и доработан для локального запуска.

## Лицензия

Учебный проект. Сторонние библиотеки распространяются по своим лицензиям.
